# 2.3 型変数

『すごいHaskellたのしく学ぼう！』第 2 章「型を信じろ！」の 2.3 節の要約。

## 型変数とは

- `head` は、どんな型のリストからでも先頭の要素を取り出せる。その型は次のとおりである。

```haskell
head :: [a] -> a
```

memo: 「head :: [a] -> a」読み方は、char(何でも可)のリストならcharがかえるよ！という意味だよね

- 小文字で始まる `a` は型ではなく、**型変数**である。「どんな型でもよい」ことを表す。
- `[a] -> a` は、「ある型のリストを受け取って、それと同じ型の値を 1 つ返す」と読む。
- 型変数を使った関数を、**多相的関数**という。

```haskell
ghci> :t fst
fst :: (a, b) -> a
```

- `a` と `b` は別の型変数だが、違う型でなければならないわけではない。この型が示しているのは、「1 つ目の要素の型と、戻り値の型が同じである」ということである。

## Ruby との違い

<details>
<summary>型変数とダックタイピング（原著外の補足）</summary>

Ruby のメソッドは、もともとどんな型の引数でも受け取る。`first` は、配列の中身が何であっても動く。

```ruby
[1, 2, 3].first        # => 1
["a", "b"].first       # => "a"
```

Haskell の `head :: [a] -> a` も、どんな型のリストにも使える。型変数は、Ruby のこの自由さを、型を確かめたまま実現する仕組みである。

違いは、関係が型に書かれている点にある。`[a] -> a` は、「戻り値の型は、リストの要素の型と同じ」と約束している。だから、`head [1,2,3]` の結果が数であることを、コンパイラは実行する前に知っている。Ruby では、`first` が何を返すかは実行するまでわからない。
